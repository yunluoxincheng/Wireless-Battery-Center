# Codex 开发任务：Wireless Battery Center 外设管理升级

你正在维护 Windows 项目 Wireless Battery Center（原 Wireless Battery 的二次开发）。本次任务是直接实现可运行的外设管理 MVP，不是重新设计架构或另做 UI。

## 开始前

阅读根目录 AGENTS.md、docs/product-positioning.md、docs/device-panel.md。检查 git status、当前分支及现有实现；继续当前功能分支，保护未提交文件。根目录 wireless-battery.zip 是用户指定的 Gemini UI 源文件，design-reference/wireless-battery/ 为现有解包参考；对照 DeviceOverview、DeviceDetail、BatteryHistoryChart、GlobalSettings、TitleBar、CSS 及参考截图，结合 panel/Main.qml、BatteryRing.qml、GlassSurface.qml、Glyph.qml。遵循项目 UI Skill。核心视觉、布局、导航、明暗主题、Liquid Glass、自定义标题栏和交互不变，新增内容融入原设计。只做原生 Qt/QML 实现，不引入原型的 Web 技术栈、另起 UI、删除或覆盖 ZIP。

先阅读 src/devices.h/.cpp、src/main.cpp、src/panel_ipc.*、现有配置/状态/驱动实现以及 panel/devicemodel.*。继续使用 C++17、Win32 + Qt 6 Quick、现有 Makefile/CMake 和本地命名管道。后台为唯一硬件轮询及档案状态源，Qt 面板按需启动；不要新增网络服务、数据库、第二套轮询或全量重构。

## 本轮必须完成（P0）

1. **持久设备档案。** 将现有进程内离线记录扩展为跨后台/面板重启的持久档案。保存稳定设备身份、可验证的名称/类别/品牌/连接信息、首次/最后在线时间（仅实际观测时更新）、最近有效电量及来源/时间、相关用户设置（复用现有配置，不造两份冲突状态）。区分当前状态与上次记录：启动后不能将历史设备当在线，接收器存在不代表鼠标在线；缓存读数不冒充实时读数；未知与无电池不能变成 0%。保留当前配置、别名、排序和任务栏/托盘行为。文件方案优先复用已有配置机制或最小独立版本化本地存储，安全写入（原子替换）、处理旧版本与损坏文件，不污染用户已有配置。仅在有效变化时合适地写入，避免每次 IPC 查询或轮询写磁盘。支持隐藏及确认后移除离线档案；再次可靠发现时可重新登记。在线设备不得被移除后立即无意义重建。
2. **发现与身份。** 将能可靠识别但无法读取电量的外设纳入面板，区别电量未知/不支持/无电池。利用已有设备来源和必要的受控枚举，过滤重复 HID 接口、系统节点及未确认接收器; 不为本轮编写新私有电量协议。区分物理设备和接口 ID；有可靠证据才合并 USB、2.4 GHz、蓝牙模式，绝不只按 VID/PID/同名合并，同型号多台保持独立。无法确定同一物理设备时明确保留独立记录，并说明限制。保持现有稳定 key/用户配置兼容。
3. **现有 UI 增量扩展。** 首页保持 Gemini 卡片网格及电量环；展示在线与离线档案，未知/无电量有可辨认表现。点击卡片进入现有详情页，可查看最近在线/最后读数、连接方式、诊断及原有设置；离线详情在刷新和重启后仍可访问。保留隐藏、排序、任务栏可见性及返回交互；新增移除确认。列表刷新不误选，不因离线自动跳页；区分设备离线与后台 IPC 断开。
4. **官方驱动入口。** 详情页加入“设备设置/官方驱动”。根据可维护的设备型号/品牌映射确定对应的官方客户端及官方网页驱动/支持页。默认优先启动已安装的本地客户端（利用已安装应用、注册表或开始菜单等可信信息），可提供用户手动选择并记住 EXE 路径的入口；未安装或启动失败时降级到已验证的官方网页驱动，再到官方支持/下载页。展示可用入口及失败原因，支持用户显式选择网页入口。若未核实 URL 则不编造，明确暂无可用驱动。首批以 ATK F1 PRO MAX、HECATE G5 和当前可确认型号为目标；不能确认兼容驱动时允许仅有支持页或无映射，不承诺全厂商。网页入口使用系统浏览器；如 WebHID 需要兼容浏览器或用户授权，提示用户。使用安全进程启动 API 和受控参数，不拼接 shell 命令、不从设备上报字符串执行程序、不自动下载/安装/提权/启动驱动，不扫描全盘。启动动作由用户点击触发。无需保证厂商支持直接跳到具体设备配置子页。
5. **保持电量功能回归。** 现有 HID/Raw Input、任务栏、托盘、低电量通知、后台单实例、刷新和缓存状态继续工作。不要修改 ATK 固件、模拟唤醒或人为平滑、修正 30%/95% 跳变；这不是本轮任务。HECATE G5 不支持电量不影响档案管理。历史曲线属于 P1；保留 Gemini 的设计参考或现有入口，不显示伪造历史数据；如已有真实历史实现，保持其功能。
