# Wireless Battery Center v0.1.0

首个 Windows x64 版本。面板采用原生 Qt Quick Liquid Glass 界面，可以查看在线和离线设备档案、最后在线时间及上次电量，并从设备详情打开厂商官方客户端或网页。后台继续提供任务栏、托盘、HID 和 Raw Input 电量监测。

| 文件 | 用途 |
| --- | --- |
| `WirelessBatteryCenter-0.1.0-windows-x64-setup.exe` | 按用户安装，在开始菜单打开 Wireless Battery Center，可选开机启动 |
| `WirelessBatteryCenter-0.1.0-windows-x64-portable.zip` | 完整解压到一个目录，再打开 `WirelessBatteryCenterPanel.exe` |
| `SHA256SUMS.txt` | 核对安装包、便携版和 HeadsetControl 源码的 SHA-256 |
| `headsetcontrol-4.3.0.tar.gz` | 随包提供的 HeadsetControl 对应源码 |

首次启动会从 Wireless Battery 只读导入受支持的设置和设备档案。版间使用独立的配置、安装和启动标识。卸载保留中心的用户数据，重装后可继续使用。此版程序尚未签名，Windows SmartScreen 可能显示提示。
