# Wireless Battery Center — 项目定位与迭代范围

更新：2026-11-21

## 产品定位

Wireless Battery Center 是基于上游 Wireless Battery 的 Windows 跨品牌外设管理中心。它统一发现、记录和展示外设，提供在线状态、电量监控、历史信息和官方驱动配置入口；不是官方驱动的替代品。保留轻量 Win32 后台、任务栏/托盘、电量协议适配，并以按需启动的 Qt Quick 面板提供管理界面。

- 管理对象是物理外设，而非仅限能够准确读取电量的无线设备。支持已确认的鼠标、键盘、耳机、手柄等；电量能力与设备存在状态分开。不要将普通 USB 控制器、复合 HID 的每个接口或未确认设备批量列入。
- 首次可靠识别后保存设备记录，跨后台/面板重启保留。离线仍可查看名称、设置入口、最后在线时间与最后有效读数；允许隐藏和移除记录。
- 官方驱动承担 DPI、RGB、宏、回报率、固件更新等配置。默认使用已安装官方客户端，未安装或启动失败时提供已核实的官方网页驱动，其次官方支持/下载页；无可信映射时明确不可用。
- 项目继续保留原仓库历史、原作者声明和 GPL-3.0 许可证。Windows v0.1.0 使用 Wireless Battery Center 产品名，拥有独立的 EXE、配置、安装、开机启动及 IPC 标识。[Windows 发布文档](windows-release.md)

## 已有基线（本次文档更新前）

- 当前分支 codex/device-management-panel；检查时 HEAD 为 d257e43（VGN V98Pro V2 2.4 GHz 电量支持）。
- Win32 后台负责硬件轮询、状态和配置；Qt 6 Quick/QML 面板经本地命名管道访问后台，按稳定 key 选择设备；已有设备详情、别名、排序、可见性、低电量通知与 Liquid Glass 外观。
- 现有离线记录只保留至本次后台退出，跨重启的设备档案、驱动跳转尚待实现。Gemini 原型包含电量历史设计，不能等同于原生面板已经具备真实历史能力。
- ATK F1 PRO MAX 的无线/有线电量跳变在官方网页驱动中亦有观察；原因未确定。保留设备原始读数及 Raw Input 刷新机制，不人为校准，不重启固件研究。HECATE G5 2.4 GHz 电量读取暂未适配成功，不阻塞设备档案功能。

## UI 设计基准

根目录 wireless-battery.zip（Gemini 原型）是权威视觉和交互参考，design-reference/wireless-battery/ 是已解包参考。实际检查 DeviceOverview.tsx、DeviceDetail.tsx、batteryHistory.ts、battery.ts、index.css 的 SHA-256 与 ZIP 对应文件相同；不代表全部文件已经比对。优先复用现有 panel/Main.qml、BatteryRing.qml、GlassSurface.qml、Glyph.qml 和主题。保留 Liquid Glass、卡片网格、详情导航、自定义标题栏、明暗主题、操作反馈与视觉层级。不得移植 React/Vite 作为运行时，也不得替换为新设计。ZIP 不得修改或擅自提交。

## P0 交付与后续范围

| 优先级 | 范围 |
| --- | --- |
| P0 | 设备档案持久化、在线/离线/未知语义、稳定身份、移除/隐藏与旧设置兼容 |
| P0 | 已知非电量设备的识别与展示（先利用可靠设备来源及最小受控扩展） |
| P0 | 现有详情页的状态、最后记录和官方客户端/网页/下载入口 |
| P0 | 驱动映射、已安装客户端检测、用户手动指定路径、失败反馈 |
| P0 | 后台/IPC/任务栏回归，真实 Qt UI 验收 |
| P1 | 真实电量历史曲线（有界、区分模式与缓存，不使用模拟数据冒充实测） |
| P1 | 更多型号的身份关联、驱动映射与设备自定义图标 |
| 暂缓 | 直接配置厂商私有功能、固件逆向与刷写、云服务、插件平台、全量设备扫描 |

身份关联只有在序列号、可信物理身份或明确型号映射等证据足够时才自动进行；不按 VID/PID、名称或接收器存在情况盲目合并同型号物理设备。证据不足时保持独立记录；本轮不强制全品牌三模式自动合并。离线记录应保持与真实在线/任务栏状态隔离。详见 [面板现状及构建](device-panel.md) 与 [Codex 开发任务](codex-device-center.md)。
